# Momo Bakehouse — Contract

## Brief Summary
Landing page for Momo Bakehouse, a cute pastel bakery brand. 8 sections: Hero, Signature Items, Menu, Our Story, Events & Workshops, Visit Us, Final CTA, Footer. Must feel like walking into a small pastel bakery — warm, cheerful, handmade, memorable.

## Viewports
- Desktop: 1440 x 900
- Mobile: 375 x 812

## Figma
In scope, but Phase C (after HTML approval).

## Acceptance Criteria
1. All 8 sections present and functional at both viewports
2. Consistent pastel visual identity (cream, pink, yellow, white)
3. DM Serif Display + DM Sans typography pairing throughout
4. Lucide icons for all iconography
5. Product cards with signature star badge system
6. Sticky navigation with prominent Order Now CTA
7. Alternating section backgrounds (white/cream) for visual rhythm
8. All CTAs clearly visible and linked
9. Photography sourced from Unsplash/Pexels, bakery-appropriate
10. Interactive prototype with working navigation flow

## Exclusions
- No e-commerce / actual cart functionality
- No user authentication
- No CMS or backend
- No actual Google Maps embed (placeholder image)
- No actual form submission
- No animations/transitions beyond hover states
- No dark mode

## Sources
- None (from scratch)
- Stock photography: Unsplash/Pexels (use)
- Icons: Lucide Icons CDN (use)
- Fonts: Google Fonts — DM Serif Display, DM Sans (use)

## Limitations
- Utopia Std and Gotham not available; using DM Serif Display and DM Sans as free alternatives
- Product photography is stock, not actual Momo products
- Map section uses a placeholder image, not a live embed
- No backend — all CTAs link to "#" as e-shop placeholder
